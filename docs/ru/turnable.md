# Turnable (звонки VK)

!!! danger "Нестабильно и не анонимно"
    Трафик идёт через серверы звонков VK, поэтому **VK видит настоящий IP
    вашего сервера** и время его использования. Кроме того, VK может в любой
    момент ограничить или сломать этот способ.

[Turnable](https://github.com/TheAirBlow/Turnable/releases/latest) заходит в
публичный звонок VK анонимным гостем и передаёт ваш трафик через серверы
звонков на сервер. Аккаунт VK не нужен. Скорость — около 250 КБ/с на
соединение, до 10 соединений с одного IP.

## Настройка

Нужны UDP-порт (по умолчанию `56000`) и ссылка на любой публичный звонок VK:

```bash
xvei add-inbound turnable --dest 'https://vk.com/call/join/CALL_ID'
```

xvei ставит Turnable 0.6.4 (с проверкой sha256). Сам он не обновляется;
`xvei check-updates` покажет, когда выйдет новая версия.

## Подключение

`xvei links` выводит две ссылки. На устройстве клиента запустите обе программы:

1. Клиент Turnable со ссылкой `turnable://`:

    ```bash
    turnable client -l 127.0.0.1:1080 'turnable://...'
    ```

2. Прокси-приложение (v2rayNG, NekoBox…) со ссылкой `vless://` — оно
   подключается к `127.0.0.1:1080`.

Если VK просит капчу, клиент Turnable выведет локальный адрес, где её можно
решить в браузере. Если новейший клиент не подключается, возьмите версию 0.6.4.
