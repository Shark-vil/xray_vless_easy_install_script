# Turnable

!!! danger "Нестабильно и не анонимно"
    Трафик идёт через сторонний сервис, поэтому **он видит настоящий IP
    вашего сервера** и время его использования. Кроме того, сервис может в
    любой момент ограничить или сломать этот способ.

[Turnable](https://github.com/TheAirBlow/Turnable/releases/latest) заходит в
публичный звонок на внешнем ресурсе анонимным гостем и передаёт ваш трафик
через его серверы на сервер. Аккаунт не нужен. Скорость — около 250 КБ/с на
соединение, до 10 соединений с одного IP.

## Настройка

Нужны UDP-порт (по умолчанию `56000`) и ссылка на любой публичный звонок:

```bash
xvei add-inbound turnable --dest 'https://vk.com/call/join/CALL_ID'
```

xvei ставит Turnable 0.7.1 (с проверкой sha256). Сам он не обновляется;
`xvei check-updates` покажет, когда выйдет новая версия.

## Подключение

`xvei links` выводит две ссылки. На устройстве клиента запустите обе программы:

1. Клиент Turnable со ссылкой `turnable://`:

    ```bash
    turnable client -l 127.0.0.1:1080 'turnable://...'
    ```

2. Клиентское приложение (v2rayNG, NekoBox…) со ссылкой `vless://` — оно
   подключается к `127.0.0.1:1080`.

Клиент нужен версии 0.7.0 или новее: ссылка использует транспорт `mpath`,
которого старые клиенты не знают. После того как xvei обновит Turnable, заново
возьмите ссылку `turnable://` из `xvei links`.

Если сервис просит капчу, клиент Turnable выведет локальный адрес, где её можно
решить в браузере. Если новейший клиент не подключается, возьмите версию 0.7.1.
