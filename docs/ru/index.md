# XVEI

**Простой менеджер настройки Xray-сервера.**

XVEI устанавливает [Xray](https://github.com/XTLS/Xray-core) на Linux-сервер,
а потом позволяет менять настройку из меню или короткими командами:
добавлять и убирать способы подключения, пускать сайты через другие серверы,
менять то, что браузер видит на вашем домене. Каждое изменение проверяется
перед применением, а перед ним делается резервная копия.

## Что умеет

- **Способы подключения (inbounds)** — VLESS (REALITY, Vision, XHTTP,
  WebSocket), Trojan, VMess, Shadowsocks, Hysteria2. Несколько из них могут
  делить порт 443. [Inbounds](inbounds.md)
- **Второй прыжок** — весь трафик или его часть через Cloudflare WARP, TOR или
  другой сервер, добавленный по ссылке. [Маршрутизация](routing.md)
- **Шаблоны стран** — сайты вашей страны никогда не открываются с IP сервера,
  чтобы сервер не заблокировали. [Маршрутизация](routing.md#шаблоны)
- **Клиентские ссылки** — ссылки, QR-коды и полные конфиги для приложений.
  [Клиенты](clients.md)
- **Готовые серверы** — уже настроенный Xray принимается как есть; ручные
  правки его конфига сохраняются.
  [Установка](install.md#сервер-с-уже-установленным-xray)
- **Резервные копии и откат**, проверка обновлений, настройка файрвола по
  желанию. [Обслуживание](maintenance.md)

## Установка

Ubuntu 20.04+, Debian 11+ или CentOS Stream 9, от **root**:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Shark-vil/xray_vless_easy_install_script/master/xvei.sh) install
```

Если нет `curl`: `apt-get update && apt-get -y install curl` (Ubuntu / Debian)
или `dnf -y install curl tar` (CentOS). По шагам —
[первая установка](getting-started.md).
