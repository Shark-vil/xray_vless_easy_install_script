# Сайт-прикрытие

Что видит браузер, если открыть ваш домен. Есть только у типов с вашим
доменом (`vless-tls`, `vless-xhttp-tls`).

| вариант | что видит браузер |
|---|---|
| `auth` | окно входа, которое ничего не принимает *(по умолчанию)* |
| `blank` | простую страницу «It works» |
| `404` | «страница не найдена» |
| `nebula`, `critters`, `game2048`, `snake`, `notes` | небольшой готовый сайт: о Солнечной системе, энциклопедия животных, игра 2048, змейка, личный блог. Ничего не загружает со стороны |
| `proxy <url>` | настоящий сайт, показанный через ваш сервер. Многие сайты так ломаются; работают: `example`, `rfc`, `cern`, `gnu`, `iana` |

```bash
xvei site game2048
xvei site proxy gnu
xvei site            # список вариантов
```

Меню: `xvei` → `5) Camouflage site`.
