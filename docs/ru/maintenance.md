# Обслуживание

## Резервные копии и откат

Перед каждым изменением через xvei текущий `config.json` (вместе с
комментариями) и настройки xvei сохраняются в
`/usr/local/etc/xray/xvei-backups/`. Хранятся последние 20.

Меню: `xvei` → `11) Backups`. Список по 10 на страницу (`n` / `p` —
листать). Откройте копию, чтобы посмотреть её конфиг, увидеть, что изменит
откат, откатиться или удалить её. `c` — сделать копию сейчас, `k` — сколько
копий хранить.

```bash
xvei backup                  # список
xvei backup restore 1        # отменить последнее изменение
xvei backup diff 3           # что изменит откат к копии 3
xvei backup create "заметка" # копия сейчас, например перед ручной правкой config.json
xvei backup keep 50          # хранить 50; 0 = без автоматических копий
```

Откат проверяется как любое изменение, а перед ним сохраняется текущий
конфиг, так что и откат можно отменить.

## Обновления

```bash
xvei check-updates
```

Показывает установленные и последние версии xvei, Xray, Hysteria2 и списков
сайтов / стран и спрашивает, что обновить (по умолчанию всё). Меню:
`10) Updates`. В git-клоне xvei обновляется через `git pull`.

## Файрвол

xvei **никогда сам не включает и не ужесточает файрвол**: неверная настройка
может отрезать доступ по SSH.

- Если ufw или firewalld уже включён и закрывает нужный xvei порт, xvei
  предложит открыть его. Он только добавляет разрешения.
- `xvei firewall status` — какие порты открыты, какие закрыты.
- `xvei firewall open` — открыть порты, нужные xvei.
- `xvei firewall setup` — блокировка по желанию: закрыть всё входящее, кроме
  SSH и портов xvei. Порт SSH определяется сам; сначала показывается план, без
  вашего «да» ничего не происходит.

Меню: `9) Firewall`.

## Сертификат

Сертификат Let's Encrypt продлевается сам. После продления хук xvei
перезапускает Xray, nginx и Hysteria2, чтобы они взяли новый сертификат.

## Удаление

```bash
xvei remove          # только xvei; Xray и остальное продолжают работать
xvei remove --all    # xvei и всё, что он настроил
```

Обе команды показывают, что будет удалено, и спрашивают подтверждение. Меню:
`12) Uninstall xvei`.

- **`xvei remove`** удаляет команду xvei, его файлы и резервные копии. Xray,
  его конфиг, nginx, WARP, TOR, Hysteria2 и сертификаты остаются и работают.
- **`xvei remove --all`** удаляет ещё Xray с конфигом, Hysteria2, Turnable,
  WARP, TOR и сайт xvei в nginx. Если Xray был на сервере до xvei, он остаётся,
  и можно вернуть его исходный конфиг. Затем xvei спрашивает, удалить ли
  пакеты, которые он ставил (nginx, certbot, tor, qrencode, docker).

Сертификаты не удаляются никогда. В скриптах добавьте `--yes` (и `--packages`,
чтобы удалить пакеты без вопроса). Git-клон не удаляется.

## Где что лежит

| путь | что |
|---|---|
| `/usr/local/etc/xray/config.json` | конфиг Xray — правится вручную или через xvei |
| `/usr/local/etc/xray/xvei-backups/` | резервные копии |
| `/usr/local/etc/xray/xvei-state.json` | настройки xvei: домен, сертификат, сайт, Hysteria2 / Turnable |
| `/usr/local/etc/xray/config.json.xvei-orig` | исходный конфиг сервера, принятого xvei |
| `/etc/hysteria/config.yaml` | конфиг Hysteria2 |
| `/etc/nginx/sites-enabled/xvei.conf` или `/etc/nginx/conf.d/xvei.conf`, `/var/www/xvei-site` | сайт-прикрытие |
| `/etc/turnable/config.json` | конфиг Turnable |
| `/usr/local/lib/xvei` | сам xvei |
