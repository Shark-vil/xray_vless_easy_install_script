# Первая установка

От пустого сервера до подключённого телефона.

## Что нужно

- VPS с Ubuntu 20.04+, Debian 11+ или CentOS Stream 9, доступ root и
  публичный IPv4-адрес.
- Открытые порты: `443/tcp` для большинства способов подключения, `80/tcp` для
  сертификата и порты, которые вы выберете в мастере.
- **Домен — только для некоторых типов.** `vless-xhttp-reality`,
  `shadowsocks`, `hysteria2` и `turnable` работают без него. Остальным нужен
  домен, A-запись которого указывает на IP сервера; настройте её до установки.

!!! note
    У многих облачных провайдеров (AWS, Oracle, Google Cloud…) есть свой
    файрвол в панели управления. xvei не может открыть там порты — сделайте это
    в панели.

Не знаете, что выбрать? Берите `vless-xhttp-reality`: домен не нужен, и
сейчас он работает хорошо. [Сравнение типов](inbounds.md).

## 1. Установите

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Shark-vil/xray_vless_easy_install_script/master/xvei.sh) install
```

Если нет `curl`, сначала поставьте его: `apt-get update && apt-get -y install
curl` (Ubuntu / Debian) или `dnf -y install curl tar` (CentOS).

Установщик ставит Xray и запускает короткий мастер. Если Xray на сервере уже
настроен, он принимается без изменений —
[подробнее](install.md#сервер-с-уже-установленным-xray).

## 2. Ответьте на вопросы мастера

Enter принимает значение в скобках.

1. **Способы подключения** — вопрос «да / нет» про каждый. Типы, которые
   работают за портом 443 (`vless-ws`, `trojan-*`, `vmess-ws`,
   `vless-xhttp-tls`), включают и `vless-tls`.
2. **Домен и e-mail** — только если выбранному типу нужен сертификат. E-mail
   передаётся только Let's Encrypt.
3. **Настройки типов** — порты, сайт, под который маскируется REALITY (по
   умолчанию `www.microsoft.com`), шифр Shadowsocks.
4. **Сайт-прикрытие** — что браузер видит на вашем домене. Можно пропустить.
5. **Шаблон маршрутизации** — если сомневаетесь, выберите `None` и оставьте
   остальное как есть: весь трафик пойдёт напрямую.
   [Шаблоны](routing.md#шаблоны)

Затем xvei получает сертификат, всё запускает и выводит ссылки.

## 3. Подключите клиент

Вывести ссылки ещё раз:

```bash
xvei links
```

Показать QR-код (тег виден в списке, например `vless_reality`):

```bash
xvei qr vless_reality
```

Импортируйте ссылку или отсканируйте код в v2rayNG, NekoBox или Hiddify —
[клиенты](clients.md).

## 4. Меняйте потом

```bash
xvei
```

В меню меняется всё, что было в мастере, и не только. Каждое изменение
проверяется и сразу применяется, предыдущий конфиг сохраняется в резервную
копию. То же самое доступно [командами](commands.md).
