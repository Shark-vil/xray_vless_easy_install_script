# Первая установка

[🇬🇧 English version](../en/getting-started.md) · [← Главная](index.md)

Эта страница проводит через первую установку: от пустого VPS до подключённого
телефона.

## Перед началом

Понадобится:

- VPS с Ubuntu 20.04+, Debian 11+ или CentOS Stream 9, доступ root и публичный
  IPv4-адрес;
- свободные порты: `443/tcp` для большинства inbounds, `80/tcp` на время
  выпуска и продления сертификата Let's Encrypt, а также порты выбранных
  inbounds;
- **домен — только если он нужен.** `vless-xhttp-reality`, `shadowsocks`,
  `hysteria2` и `turnable` работают без домена. `vless-tls`, `vless-ws`,
  `vless-xhttp-tls`, `trojan-*` и `vmess-ws` требуют домен с A-записью на IP
  сервера — создайте запись до установки и дождитесь, пока она начнёт
  резолвиться.

> [!NOTE]
> У многих облачных провайдеров (AWS, Oracle Cloud, Google Cloud, …) есть свой
> файрвол в панели управления («security group», «security list»). xvei не
> может открыть там порты — откройте их в панели сами.

Не знаете, какие inbounds выбрать? Начните с `vless-xhttp-reality`: домен не
нужен, и это один из рекомендуемых вариантов в 2026. Подробнее —
[inbounds](inbounds.md#какой-inbound-выбрать-2026).

## 1. Установите curl

Ubuntu / Debian:

```bash
apt-get update && apt-get -y install curl
```

CentOS:

```bash
dnf -y install curl tar
```

## 2. Запустите установщик

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Shark-vil/xray_vless_easy_install_script/master/xvei.sh) install
```

Установщик проверит систему, поставит зависимости и Xray, затем запустит
мастер.

> [!TIP]
> Если на сервере уже настроен Xray, ничего не устанавливается и не меняется:
> существующая настройка принимается как есть. См.
> [установку](install.md#сервер-с-уже-установленным-xray).

## 3. Ответьте на вопросы мастера

Мастер задаёт вопросы в таком порядке. Enter принимает значение в скобках.

1. **Какие inbounds включить** — по вопросу «да/нет» на каждый тип. По
   умолчанию предлагается только `vless-tls`. Inbounds, которые работают за
   портом 443 (`vless-ws`, `trojan-*`, `vmess-ws`, `vless-xhttp-tls`),
   автоматически включают `vless-tls`.
2. **Домен и e-mail** — спрашиваются, если выбранному inbound нужен
   сертификат (или для `hysteria2`). E-mail передаётся только Let's Encrypt.
3. **Настройки каждого inbound**:
   - `vless-xhttp-reality` — порт (443, если свободен, иначе 8443) и сайт для
     маскировки (по умолчанию `www.microsoft.com`);
   - `shadowsocks` — порт и шифр;
   - `hysteria2` — UDP-порт;
   - `turnable` — UDP-порт и ссылка на звонок VK (сначала прочитайте
     [предупреждения](turnable.md)).
4. **Сайт-прикрытие** — что видит браузер на вашем домене. Можно пропустить и
   поменять потом через `xvei site`.
5. **Шаблон маршрутизации** — как трафик уходит с сервера. Если сомневаетесь,
   выберите `none` и «Everything direct»; шаблоны описаны в разделе
   [маршрутизация](routing.md#шаблоны-маршрутизации).

После последнего ответа xvei запросит сертификат (если нужен), запишет
конфиги, проверит их, запустит сервисы и выведет клиентские ссылки.

## 4. Подключите клиента

Ссылки выводятся в конце установки. Вывести их снова в любой момент:

```bash
xvei links
```

Показать QR-код одного inbound (тег виден в списке, например `vless_reality`):

```bash
xvei qr vless_reality
```

Импортируйте ссылку или отсканируйте QR-код в клиентском приложении — v2rayNG,
NekoBox или Hiddify, см. [клиенты](clients.md). Полные клиентские конфиги
сохраняются в `~/xray_eis/`.

## 5. Меняйте настройки потом

Откройте меню:

```bash
xvei
```

Там можно поменять всё, что спрашивал мастер: добавить или удалить inbounds,
включить WARP или TOR, добавить правила, сменить шаблон, поменять сайт. Каждое
изменение проверяется и применяется сразу. То же самое доступно командами — см.
[команды](commands.md).

## Пример: без домена, один inbound

Ответьте **да** только на «VLESS XHTTP + REALITY», примите порт и сайт по
умолчанию, остальное пропустите и выберите шаблон `none` с «Everything
direct». Получится один inbound на порту 443 без домена и сертификата.
